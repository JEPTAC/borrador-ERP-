REEMPLAZO DEL MÓDULO DE TALENTO HUMANO

1. En el repositorio del ERP ubique:
   apps/secretaria-general/talento-humano/

2. Elimine o renombre la carpeta talento-humano actual.

3. Copie esta carpeta talento-humano completa en la misma ubicación.

4. No debe reemplazar assets, Secretaría General ni otros módulos.

5. GitHub Pages cargará los datos desde cada data.json. Las operaciones de demostración se guardan en localStorage del navegador.

Contenido: 19 páginas independientes, cada una con index.html, styles.css, script.js y data.json, más una carpeta shared para estilos y utilidades comunes.
