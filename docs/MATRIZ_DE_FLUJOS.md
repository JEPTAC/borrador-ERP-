# Matriz resumida de flujos

| Proceso | Inicia | Resultado esperado | Siguiente responsable |
|---|---|---|---|
| Crear pedido | Ventas | Pedido PVC, PVN, PVE o PVP creado | Compras, Caja/Cartera o Recepción según condición |
| Solicitud de crédito | Ventas | Expediente enviado con 15 documentos | Cartera |
| Revisión de crédito | Cartera | Aprobada, rechazada o devuelta | Ventas consulta/corrige |
| Compras | Compras | PVE gestionado y liberado | Recepción |
| Recepción de mercancía | Recepción | Ingreso conforme/no conforme y stickers | Operación / control |
| Recepción de pedidos | Recepción/Logística | Pedido aceptado | Alistamiento |
| Alistamiento | Logística | Material preparado o novedad registrada | Corte o Facturación |
| Corte | Auxiliar de corte | Corte ejecutado con evidencias | Alistamiento/Facturación |
| Facturación | Facturación | Documento y salida validados | Despacho |
| Caja | Caja | Pago o soporte validado | Flujo operativo |
| Liberación por cartera | Cartera | Pedido financiero liberado | Flujo operativo |
| Despacho | Logística/Despacho | Entrega registrada y cerrada | Cierre |
| VSM | Roles autorizados | Medición de tiempos y esperas | Mejora continua |

## Regla de PVP

PVP es un tipo de pedido válido y conserva el mismo flujo operativo general. Su etiqueta debe mantenerse durante toda la trazabilidad.

## Regla de solicitudes de crédito

Ventas crea, carga, corrige y envía. Cartera recibe, revisa y decide. Auditoría y Gerencia consultan sin intervenir en la decisión, salvo definición formal posterior.
